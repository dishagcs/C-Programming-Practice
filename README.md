# 💻 C Programming Practice

## 📌 About
This repository contains C programs I'm writing while learning C from 
scratch — covering basics, ASCII/character manipulation, operators, 
and decision-making (if-else). Each program includes comments explaining 
the logic.

## 📂 Topics Covered
- Basic I/O (printf, scanf)
- Character & ASCII conversions
- Operators (arithmetic, relational, logical)
- Decision making using if-else
- Number manipulation (digit extraction, reversal)

## 📜 Programs List

| # | Program | Concept Used |
|---|---------|--------------|
| 1 | Print "Hello, World!" | Basic program structure |
| 2 | Print decimal (ASCII) value of a character | char, %d vs %c |
| 3 | Convert uppercase to lowercase | ASCII (+32) |
| 4 | Convert lowercase to uppercase | ASCII (-32) |
| 5 | Convert digit to digit character | ASCII (+48) |

| 8 | Sum of two digit characters | ASCII conversion + addition |
| 9 | Sum and product of two numbers | Arithmetic operators |

| 13 | Currency note breakdown (500/100/10) | % and / operators |
| 14 | Swap two variables (using temp variable) | Assignment operators |
| 15 | Swap two variables (without temp variable) | Arithmetic operators |

## 🎯 What I'm Learning
- How C handles characters internally as ASCII numbers
- Difference between format specifiers (%d, %c, %f)
- Writing clean, logical programs using operators
- Decision-making using if-else statements
